## Quick Start

```bash
# Install dependencies
make install

# Start Neo4j (Docker)
make docker-up

# Seed sample data
make seed

# Start the application
make start
```

- **Backend:** http://localhost:8000
- **Frontend:** http://localhost:3000
- **Neo4j Browser:** http://localhost:7474

## Agent Tools

The AI agent has access to the following domain-specific tools:

- **lookup_field_semantics** — Look up enterprise field definitions and their mapped business concepts
- **search_sales_documents** — Search sales documents and retrieve their semantic source view
- **search_machine** — Search for machines by name, type, or status
- **get_work_orders** — Get work orders filtered by status or priority
- **quality_analysis** — Analyze quality metrics for a specific part or production line
- **supplier_performance** — Evaluate supplier performance based on quality and delivery
- **production_metrics** — Get production efficiency and output metrics for production lines
- **list_machines** — List Machine records with optional limit
- **get_machine_by_id** — Get a specific Machine by ID with all connections
- **execute_cypher** — Run ad-hoc Cypher queries
- **get_schema** — View the graph schema

## Agent Framework: Strands

This project uses [Strands Agents](https://github.com/strands-agents/strands-agents) with `@tool` decorators and an Anthropic-backed model. Requires `ANTHROPIC_API_KEY` in your `.env` file. Runs synchronously via `asyncio.to_thread()`.

Streaming is limited to real-time tool call visualization; text arrives after the agent completes.

See `backend/app/agent.py` for the full implementation.


## Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

| Variable | Description |
|----------|-------------|
| `NEO4J_URI` | Neo4j connection URI |
| `NEO4J_USERNAME` | Neo4j username |
| `NEO4J_PASSWORD` | Neo4j password |
| `NEO4J_DATABASE` | Database name — blank uses the driver default (`neo4j`); set for instances whose database has another name (common on Aura API/CLI-provisioned instances) |
| `ANTHROPIC_API_KEY` | Anthropic API key for the AI agent |
| `OPENAI_API_KEY` | OpenAI API key (for embeddings) |
| `SESSION_STRATEGY` | Memory session strategy (per_conversation, per_day, persistent) |
| `BACKEND_PORT` | Backend port (default: 8000) |
| `FRONTEND_PORT` | Frontend port (default: 3000) |

## Troubleshooting

### Neo4j Connection Errors

**"Neo4j is unavailable" on all endpoints**
- Verify your `.env` file has correct `NEO4J_URI`, `NEO4J_USERNAME`, and `NEO4J_PASSWORD`
- Run `make test-connection` to validate credentials

**`/health` shows `"status": "degraded"` with a `memory_error` while chat still works**
- The Neo4j connection is fine but memory writes are failing — most often the
  database name: if your instance's database isn't literally named `neo4j`
  (common on Aura instances provisioned via the Aura API/CLI), set
  `NEO4J_DATABASE` in `.env` and restart
- `memory_error` is the classified category (`auth`/`rate_limit`/`network`/`config`/`unknown`);
  `memory_error_detail` carries the short technical detail
- Run `make docker-up` first, then wait a few seconds for Neo4j to start

**Extra variables in `.env`**
- The backend accepts extra environment variables, so standard Neo4j Aura `.env` exports (with `NEO4J_DATABASE`, `AURA_INSTANCEID`, etc.) work without editing

### Backend Issues

**Port already in use**
- Change `BACKEND_PORT` in `.env` (default: 8000)
- Kill existing process: `lsof -ti:8000 | xargs kill`

**API key not set**
- Set `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` in `.env` depending on your agent framework

### Frontend Issues

**Build errors after `npm install`**
- Delete `node_modules` and `package-lock.json`, then run `npm install` again
- Ensure Node.js 18+ is installed
