3. Create constraints and indexes  
4. Load ontology entities  
5. Load ontology relationships  
6. Load provenance anchors  
7. Load semantic anchors  
8. Validate the graph structure  
9. Expose the ontology through the librarian  
10. Allow Copilot to query the graph directly  

This is the transition from “ontology artifacts” to “ontology graph.”
