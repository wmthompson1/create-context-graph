### Step 0 — Baseline: what the tutorial is doing

use the financial cost management domain

---

### Step 1 — Render the tutorial app

Ask the agent to:

1. Use `ProjectRenderer` with **financial cost management domain** 
2. Render into a fresh temp directory or a `first-context-graph-app` folder.

Concretely (pattern, not exact command):

- `ProjectConfig(project_name='First Context Graph App', domain='<tutorial-domain>', framework='strands', neo4j_type='existing')`
- `ProjectRenderer(config, load_domain('<tutorial-domain>')).render(output)`

**What to look for in the scaffold:**

- `context-graph/<tutorial-domain>/domain.yaml`
- `context-graph/<tutorial-domain>/tools/*.yaml`
- `backend/app/agent.py`
- `backend/app/<tutorial-domain>_reasoning.py` (or equivalent)

This mirrors what you already validated for manufacturing, just with a simpler domain.

---

### Step 2 — Inspect the scaffold vs manufacturing

With both projects rendered (tutorial app and manufacturing app), compare:

- **Context‑graph package**
  - Tutorial: likely has a small domain and a minimal tools catalog.
  - Manufacturing: has `domain.yaml`, `manufacturing-tools.yaml`, and `reasoning/strategies.yaml` with bounded Cypher strategies.

- **Backend startup**
  - Tutorial: loads a basic domain and tools, may or may not validate reasoning catalogs.
  - Manufacturing: explicitly validates all three catalogs at startup, enforces `salt.manufacturing.v1.1`, read‑only Cypher, and `max_hops: 4`.

- **Agent module**
  - Tutorial: simple agent with 1–2 tools wired.
  - Manufacturing: six catalog‑backed tools, evidence prompt contract, SSE tool‑event citations.

You’re basically checking that your manufacturing scaffold is a **strict superset** of the tutorial’s baseline.

---

### Step 3 — Run the tutorial backend

Ask the agent to:

1. Install the backend dependencies for the tutorial app (from its `pyproject.toml`).
2. Start the FastAPI server (usually `uvicorn backend.app.main:app` or similar).
3. Hit the tutorial’s agent endpoint (often `/agent` or `/chat`) with the example query from the tutorial.

Goal: see a **simple, successful graph‑backed response** in the tutorial domain.

---

### Step 4 — Run the manufacturing backend in parallel

Then, do the same with your **manufacturing app**:

1. Install dependencies (including `pyyaml>=6.0`).
2. Start the backend.
3. Call the manufacturing agent with one of your demo questions, e.g.:

- “For WorkOrder WO‑2048, what parts are required and through which BOM?”
- “Are there overlapping schedule slots for WorkCenter WC‑17 tomorrow?”

You should see:

- evidence‑bound answers  
- citations to node IDs / relationships  
- no GDS usage  
- no writes
